# Pertemuan 17: Struktur Data Graph

## Deskripsi
Pertemuan 17 membahas konsep teori Graf (Graph), sejarahnya, terminologi (simpul/vertex, tepi/edge, derajat, path, cycle), manfaat aplikasi graf di dunia nyata, serta representasi data graf menggunakan Adjacency List dan Adjacency Matrix maupun pustaka Python seperti NetworkX.

## Program yang Tersedia
1. `01_representasi_graph.py`: Representasi data graf menggunakan struktur Adjacency List dan matriks 2D Adjacency Matrix (Studi kasus kota Skotlandia).
2. `02_graph_networkx_basic.py`: Penggunaan modul `networkx` untuk mengonstruksi node dan edge serta menghitung derajat graf.

## Cara Menjalankan
Jalankan file yang diinginkan:
```bash
python 01_representasi_graph.py
python 02_graph_networkx_basic.py
```
